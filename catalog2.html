KEY FEATURES

Intelligent Input
Technology

🧠

Intelligent IME Parsing

한글 초성·중성·종성을 분석하여 한/영 입력 상태에 맞는 키 입력 흐름을 구성합니다.

한/영 자동 전환 · 혼합 문장 · 소스코드 · 명령어
